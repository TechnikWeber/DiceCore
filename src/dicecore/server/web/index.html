Start on Folder — it plays back images from a directory, so everything here works before any hardware arrives.

CSI camera module

A Pi only binds a sensor the firmware knows. The official modules are auto-detected; Arducam's are not — they need camera_auto_detect=0 plus an explicit dtoverlay= and a reboot. Picking it here writes that for you.

What the system sees

Engine

Classic counts pips and needs no training. Model reads numerals too, once you have taught it your dice. Remote lets another machine do the reading — that is how a Pi Zero keeps up.

Tray

Everything outside the tray is ignored — the cheapest accuracy win there is. Values are fractions of the frame, so they survive a resolution change.

Classic engine

Settling

A frame grabbed mid-tumble is worthless. The engine waits until the picture stops changing before it reads.

Teach it your dice

Roll, glance, correct. Every confirmed roll is a training sample — there is no separate labelling tool and no command line. Aim for a hundred rolls to start with, and watch the thin faces below.
